About

BCA graduate from Somaiya Vidyavihar University, currently an Associate Software Engineer at Algorisys Technologies. Day to day I architect high-throughput distributed ETL pipelines in Go, ship zero-downtime features for critical HRMS platforms, and manage Linux server infrastructure end to end, including pipelines that process millions of rows across distributed client servers.

Before that I interned at Algorisys on MERN tools and a graphics engine in C. Outside work I ship open-source and personal tools when a real problem shows up.
