/about

I'm a Software Engineer and BCA graduate from Somaiya Vidyavihar University, currently working as an Associate Software Engineer at Algorisys Technologies. My day-to-day is architecting high-throughput distributed ETL pipelines in Go, shipping zero-downtime features for critical HRMS platforms, and managing Linux server infrastructure end to end.

It started with a curiosity for how things work under the hood - AI-powered tools and MERN stack apps during my internship, then further back, building a graphics engine from scratch in C.

Outside work I build things that solve real problems: tm1go, an open-source Go package for TM1 APIs; Fluxroom, a real-time collaborative editor; and a couple of approximate calorie trackers I keep rewriting for fun.
