## Fidelity inventory (from approved comp)
- Component grammar: one-bit windows (black title bar, white close box left, title centered, 1px chrome), chunky one-bit buttons, 32px two-color desktop icons with pixel labels, top menu bar with dropdowns.
- Corner language: square everywhere; hard pixel edges; zero radius.
- Line weights: 1px black borders; dithered (stipple) fills are the only gray.
- Elevation: flat; windows separate via 1px chrome + offset outline, never soft shadows.
- Type ramp: pixel display caps (Chicago-class, e.g. Silkscreen) for title bars, headings, buttons, icon labels; Geneva-class small sans (Geneva/Verdana) for body paragraphs.
- Signature states: marching-ants selection, inverted-black press/hover, dotted drag outline.
- Media: icons, dither, chrome are SVG/CSS/canvas (hard-edged shape systems); no raster required; text never rasterized.

## Constraints
- Static HTML/CSS/JS on GitHub Pages; single finish (no theme toggle — the world is one-bit); reduced-motion honored; mobile responsive (menu bar collapses, icons re-flow).
- Deferred: window dragging, zoom-rect open animations (post-v1 candidates).
